## Project Structure

```
ridhimaridi.github.io/
├── index.html    # Page structure and content
├── style.css     # Colors, fonts, gradients, animations, and responsive rules
├── script.js     # Starfield, mobile menu, scroll effects, and reveal animations
└── README.md     # This file
```

No build step, package manager, or framework is needed.

---

## Running Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/ridhimaridi/ridhimaridi.github.io.git
   ```
2. Open `index.html` in any modern browser.

The site runs as static files, so no server is required.

---

## Deploying to GitHub Pages

1. Upload the files to the `main` branch of the repository `ridhimaridi.github.io`.
2. On GitHub, go to **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
4. Choose branch `main` and folder `/ (root)`, then click **Save**.
5. After a minute or two, the site is live at **https://ridhimaridi.github.io**.

## Technologies Used

- **HTML5** for structure and semantic sections
- **CSS3** for the gradient theme, glass-style cards, animations, and responsive layout
- **JavaScript (vanilla)** for the starfield, mobile navigation, active-link highlighting, and scroll reveal effects
- **Google Fonts** (Pinyon Script, Cormorant Garamond, and Quicksand), loaded from the web

---

## Customization

- **Colors:** edit the variables at the top of `style.css` (`--violet`, `--purple`, `--lilac`, `--black`, and so on). The background gradient is in the `body` rule.
- **Fonts:** change `--font-script`, `--font-display`, and `--font-body` in `style.css`, and update the Google Fonts link in `index.html`.
- **Content:** edit the sections in `index.html`.
- **Star density:** change the `count` value in `script.js`.
