# Rayan Chowdhury Ridi · Portfolio

A personal portfolio website for **Rayan Chowdhury Ridi**, a Computer Science and Engineering student at the International University of Business Agriculture and Technology (IUBAT), Dhaka, Bangladesh.

The site uses a dark space theme with blue and white gradients, animated starfield and nebula backgrounds, and a responsive layout that works on phones, tablets, and desktops.

## Project Structure

```
rayan-portfolio/
├── index.html    # Page structure and content
├── style.css     # Theme, layout, animations, and responsive rules
├── script.js     # Starfield, mobile menu, scroll effects, and reveal animations
└── README.md     # This file
```

No build step, package manager, or framework is needed.

---

## Running Locally

1. Download or clone the repository:
   ```bash
   git clone https://github.com/rayanridi/rayan-portfolio.git
   ```
2. Open `index.html` in any modern browser.

That's all. The site runs as static files.

---

## Deploying to GitHub Pages

1. Push the files to the `main` branch of the repository `rayan-portfolio`.
2. On GitHub, go to **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
4. Choose branch `main` and folder `/ (root)`, then click **Save**.
5. After a minute or two, the site is live at `https://rayanridi.github.io/rayan-portfolio/`.

## Technologies Used

- **HTML5** for structure and semantic sections
- **CSS3** for the theme, gradients, glass-style cards, animations, and responsive layout
- **JavaScript (vanilla)** for the starfield, mobile navigation, active-link highlighting, and scroll reveal effects
- **Google Fonts** (Orbitron and Inter), loaded from the web

---

## Customization

- **Colors:** edit the CSS variables at the top of `style.css` (`--blue`, `--cyan`, `--black`, and so on).
- **Content:** edit the sections in `index.html`.
- **Star density:** change the `count` value in `script.js`.
